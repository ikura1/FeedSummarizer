Instagram 片思いフォロー チェッカー

自分はフォローしているのに、相手からはフォローされていないアカウント(片思いフォロー)を一覧表示します。すべてブラウザ内で処理され、外部には一切送信されません。

1. Instagramからデータをエクスポートする

  1. Instagramアプリ(またはWeb)で「設定とプライバシー」→「アカウントセンター」→「自分の情報とアクセス許可」→「情報をダウンロード」を開く
  2. 対象アカウントを選び、「一部の情報をダウンロード」から「つながり」(フォロワー・フォロー中)を選択
  3. 形式は必ず JSON を選択してリクエスト
  4. 準備が完了したらメールまたはアプリの通知からダウンロードし、ZIPを解凍する
  5. 解凍後の connections/followers_and_following/ フォルダ内にある followers_1.json と following.json(バージョンによっては relationships_following.json)を用意する

2. ファイルをアップロードして比較
